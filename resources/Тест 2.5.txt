Глава 1. ВВЕДЕНИЕ

Данное руководство предназначено для пользователей программного комплекса "Архитектор-Эксперт", разработанного для автоматизации проектирования строительных конструкций с использованием методов искусственного интеллекта. В состав комплекса входят модули для создания расчетных схем, выполнения прочностных расчетов, оптимизации параметров конструкций и генерации проектной документации.

Рекомендуется внимательно изучить данное руководство перед началом работы. В случае возникновения технических вопросов обращайтесь в службу поддержки по телефону 8-800-123-45-67 или по электронной почте support@architect-expert.ru.

Системные требования:
- Операционная система: Windows 10/11, Linux (Ubuntu 20.04+), macOS 12+
- Процессор: Intel Core i5 или эквивалент, 2.5 ГГц
- Оперативная память: 8 ГБ (16 ГБ для сложных проектов)
- Видеокарта: с поддержкой OpenGL 4.5, 2 ГБ памяти
- Свободное место на диске: 20 ГБ
- Разрешение экрана: 1920x1080 или выше

Глава 2. УСТАНОВКА И НАСТРОЙКА

Установка программного комплекса осуществляется с помощью инсталляционного пакета. Перед установкой убедитесь, что соблюдены системные требования, а в системе отключены программы антивирусной защиты (возможны ложные срабатывания на установщик). Запустите файл setup.exe и следуйте инструкциям мастера установки.

После установки необходимо выполнить настройку параметров работы с использованием утилиты "Конфигуратор". В конфигураторе можно указать пути к библиотекам материалов, настроить параметры отображения и задать единицы измерения (по умолчанию установлена система СИ).

Важно! При первом запуске система предложит зарегистрировать лицензионный ключ. Лицензионный ключ представляет собой 25-значный алфавитно-цифровой код, который выдается после приобретения продукта и связывается с аппаратной конфигурацией компьютера.

Если при активации возникает ошибка "Invalid license key", проверьте правильность ввода ключа и наличие активного интернет-соединения.

Глава 3. ИНТЕРФЕЙС ПОЛЬЗОВАТЕЛЯ

Главное окно программы содержит следующие элементы:
1. Меню приложения (в верхней части окна)
2. Панель инструментов (набор кнопок быстрого доступа)
3. Рабочая область (место для отображения и редактирования модели)
4. Дерево проекта (отображает иерархию элементов конструкции)
5. Панель свойств (показывает параметры выбранного элемента)
6. Консоль вывода (отображает сообщения системы и результаты расчетов)

Основные команды управления моделью доступны через панель инструментов: создание элемента, копирование, перемещение, удаление, поворот, масштабирование.

Сочетания горячих клавиш:
- Ctrl+N: создать новый проект
- Ctrl+O: открыть существующий проект
- Ctrl+S: сохранить проект
- Ctrl+Z: отменить последнее действие
- Ctrl+Y: повторить отмененное действие
- Ctrl+C: копировать выделенные элементы
- Ctrl+V: вставить элементы из буфера обмена
- Ctrl+A: выделить все элементы
- Delete: удалить выделенные элементы
- Ctrl+Shift+S: сохранить проект как
- F1: открыть справочную систему

Глава 4. РАБОТА С ПРОЕКТОМ

4.1. Создание нового проекта

Для создания нового проекта выберите в меню "Файл → Создать проект" или используйте комбинацию клавиш Ctrl+N. В появившемся окне укажите имя проекта, тип конструкции (здание, мост, башня, мачта, опора ЛЭП) и единицы измерения. Для типовых проектов доступны шаблоны, которые позволяют быстро создать проект с заранее настроенными параметрами.

После создания проекта в дереве проекта автоматически добавляются узлы: "Материалы", "Сечения", "Нагрузки", "Сочетания нагрузок", "Группы элементов". При необходимости вы можете изменить иерархию структуры проекта с помощью контекстного меню.

Если вы планируете использовать нестандартные материалы, перейдите в узел "Материалы" и нажмите "Добавить материал". При добавлении нового материала с параметрами, которых нет в базе материалов, будет использоваться автоматическая проверка и сохранение в локальной базе.

Правило: Если значение предела текучести материала неизвестно или не задано, расчет по предельным состояниям выполняться не будет. Система выдаст предупреждение и предложит ввести значение или выбрать материал из библиотеки.

4.2. Импорт и экспорт данных

Программный комплекс поддерживает импорт и экспорт данных в следующих форматах: DXF, DWG, IFC, STEP, IGES. Для импорта выберите "Файл → Импорт → [формат]" и укажите файл. При импорте система выполняет автоматическую проверку геометрии, исправляет ошибки и при необходимости предлагает варианты восстановления данных.

Экспорт модели осуществляется через "Файл → Экспорт → [формат]". При экспорте можно выбрать набор экспортируемых данных: только геометрия, с нагрузками, с результатами расчетов, полный проект. Для совместимости с другими программными продуктами рекомендуется использовать формат IFC.

Перед экспортом выполняется проверка целостности модели. При обнаружении неопределенных или неполных данных пользователь получает детализированный отчет с перечнем проблем.

Примечание: При импорте из AutoCAD возможно искажение криволинейных поверхностей, преобразованных в аппроксимирующие ломаные линии. Рекомендуется предварительно упрощать геометрию в исходной программе.

Глава 5. РАСЧЕТ И АНАЛИЗ КОНСТРУКЦИЙ

5.1. Назначение нагрузок

Для назначения нагрузок перейдите на вкладку "Нагрузки". В программном комплексе доступны следующие типы нагрузок: собственный вес, полезная нагрузка, снеговая нагрузка, ветровая нагрузка, сейсмическая нагрузка, температурные воздействия. Каждый тип нагрузки настраивается в соответствии с действующими нормами: СП 20.13330.2016 (Россия), EN 1991 (Европа), IBC (США).

При назначении ветровой нагрузки необходимо учитывать пульсационную составляющую, которая зависит от высоты здания, типа местности и формы конструкции. Программа автоматически вычисляет аэродинамические коэффициенты на основе введенных геометрических параметров.

Если конструкция имеет сложную форму, рекомендуется использовать вычислительный аэродинамический модуль для уточнения распределения ветрового давления.

Правило: При одновременном действии постоянных и длительных нагрузок коэффициент надежности по нагрузке принимается равным 1.1 для бетонных конструкций и 1.05 для стальных конструкций. Для переменных нагрузок значение коэффициента зависит от нормативной продолжительности действия нагрузки. Если нагрузка действует менее 6 часов в сутки, коэффициент может быть снижен на 10%.

5.2. Выполнение расчета

Для выполнения расчета нажмите кнопку "Выполнить расчет" на панели инструментов или выберите "Расчет → Выполнить расчет". Система автоматически проверит подготовленность модели: наличие материалов, сечений, нагрузок и правильность задания граничных условий.

Перед расчетом можно выбрать тип расчета: линейный статический, физически нелинейный, геометрически нелинейный, динамический (сейсмический, ветровой, от технологических нагрузок), устойчивость, частотный анализ, спектральный анализ. Каждый тип расчета требует соответствующей настройки параметров сходимости.

Важно! Для сложных нелинейных расчетов рекомендуется постепенное увеличение нагрузки с шагом 5-10%, что позволяет контролировать процесс сходимости. При расхождении решения требуется уменьшить шаг нагружения до 1-2% или использовать альтернативный метод решения.

Если расчет прерывается с ошибкой "Maximum number of iterations exceeded", увеличьте число итераций или измените параметры сходимости (допуски) в настройках расчета.

5.3. Анализ результатов

После завершения расчета результаты отображаются в виде эпюр, полей напряжений, деформированных схем, таблиц усилий и реакций. Для выбора типа отображения используется панель "Визуализация результатов". Доступны варианты: непрерывное поле, изолинии, изополя, векторное поле, контурное отображение.

Можно просматривать отдельные комбинации нагрузок или общую картину нагружения. Для создания отчетов используется встроенный инструмент "Генератор отчета", который позволяет включить в отчет выбранные графики, таблицы и изображения.

В отчет рекомендуется включать:
- Краткое описание модели с указанием типа, геометрии, материалов
- Значения нагрузок и их комбинаций
- Результаты расчетов в табличной форме и графическом виде
- Наиболее опасные сечения и проверки прочности
- Заключение о соответствии нормативным требованиям

Если в результате расчета выявлены значения напряжений, превышающие допустимые на 15-20%, программа автоматически предложит изменить параметры модели: размеры сечений, марку материала, добавить ребра жесткости или армирование. При необходимости можно запустить автоматическую оптимизацию параметров с заданными ограничениями.

Правило: Если перемещения узлов превышают предельно допустимые значения, предусмотренные нормами, и запас прочности по несущей способности менее 5%, конструкция считается недопустимой. Требуется корректировка параметров. Если запас прочности более 20% и перемещения не превышают допустимых, конструкция считается недопустимо экономичной. Рекомендуется оптимизация.

5.4. Проверка на устойчивость

Расчет на устойчивость выполняется для элементов, работающих на сжатие и изгиб. Коэффициент устойчивости зависит от гибкости элемента, которая определяется отношением расчетной длины к радиусу инерции сечения. При расчетной длине более 3 метров рекомендуется проверка на устойчивость по двум формам потери устойчивости.

Для стальных конструкций типа балок или колонн с гибкостью более 120 рекомендуется усиление сечения с использованием ребер или изменение схемы креплений. Если гибкость превышает 200, использование такого элемента возможно только при жестком защемлении на концах и наличии дополнительных связей.

В случаях, когда гибкость составляет 80-120 и нагрузка близка к предельной, рекомендуется выполнить проверку на устойчивость с учетом влияния начальных несовершенств и остаточных напряжений.

Для сжатых стержней с несимметричным сечением требуется выполнять проверку устойчивости для двух главных плоскостей инерции, а также для крутильной формы потери устойчивости.

Глава 6. ПОСТРОЕНИЕ И ОПТИМИЗАЦИЯ МОДЕЛИ

6.1. Автоматическое построение модели

Для ускорения процесса моделирования в комплексе реализованы инструменты автоматического построения параметрических моделей. Доступны следующие типы параметрических конструкций: рамы, балки, колонны, фермы, арки, купола, пространственные сетчатые конструкции, висячие системы.

При использовании параметрического построения пользователь задает основные геометрические параметры, а программа автоматически создает конечно-элементную модель с разбивкой на конечные элементы. Для конструкций с регулярной структурой это позволяет сократить время моделирования на 70-80%.

В случае необходимости детализации в отдельных зонах (узлы, опоры, места приложения нагрузок) можно задать параметры локального сгущения сетки конечных элементов.

Если конструкция включает многослойные элементы или элементы с изменяемым сечением по длине, это также учитывается в параметрической модели автоматически.

Правило: При моделировании конструкций из элементов с изменяемым сечением необходимо задать не менее 4 промежуточных точек для обеспечения точности расчета. Если изменение сечения превышает 30% по высоте, рекомендуется увеличить количество точек до 6-8.

6.2. Оптимизация параметров

Встроенный модуль оптимизации позволяет находить оптимальные параметры конструкции по критериям: минимальный вес, минимальная стоимость, максимальная жесткость, минимальные перемещения, максимальная прочность.

Параметрами оптимизации могут выступать размеры сечений, марки материалов, шаг элементов, количество элементов, класс бетона, тип армирования. Оптимизация выполняется с использованием эволюционных алгоритмов или метода градиентного спуска, выбор зависит от типа задачи и допустимого времени счета.

Перед запуском оптимизации необходимо задать целевой показатель, ограничения (по прочности, устойчивости, перемещениям, частотам колебаний) и ограничения варьируемых параметров. Рекомендуется сохранять резерв прочности 5-10% от предельных значений для учета разброса свойств материалов и неточностей изготовления.

Если оптимизация не дает улучшения параметров более чем на 1% за 50 итераций, выполняется проверка достижения локального минимума, и в случае необходимости алгоритм перезапускается с другими начальными условиями.

Примечание: Для конструкций с большим количеством варьируемых параметров (более 15) рекомендуется использовать метод эволюционного моделирования, позволяющий работать со сложными многокритериальными задачами.

Глава 7. ГЕНЕРАЦИЯ ПРОЕКТНОЙ ДОКУМЕНТАЦИИ

После завершения расчетов и оптимизации программа автоматически генерирует комплект проектной документации в соответствии с требованиями ГОСТ Р 21.1101-2023. В комплект входят:
- Пояснительная записка с описанием конструктивных решений
- Сборочные чертежи с размерами
- Спецификации элементов
- Ведомости материалов
- Арматурные чертежи
- Калькуляция объемов работ
- Технико-экономические показатели
- Заключение по результатам расчетов

Правильно оформленная документация содержит полный набор данных для изготовления и монтажа. При необходимости можно включить в состав документации файлы для ЧПУ (управляющие программы для станков с ЧПУ).

При формировании чертежей автоматически расставляются размерные цепочки, обозначения профилей и марок материалов в соответствии с ЕСКД. Внесение изменений в модель автоматически перестраивает чертежную документацию, что исключает расхождения между расчетной моделью и проектом.

Если требуется изменить оформление документации (например, для другого заказчика или региональных норм), доступны пользовательские шаблоны и настройки стилей чертежей.

Глава 8. УСТРАНЕНИЕ НЕИСПРАВНОСТЕЙ

8.1. Типичные ошибки и их решение

В процессе работы могут возникать различные ошибки. Ниже приведены наиболее часто встречающиеся проблемы и способы их решения.

Если происходит вылет программы при выполнении расчета, возможно, используется устаревшая версия драйвера видеокарты. Рекомендуется обновить драйвер до последней версии или переключиться на программную визуализацию в настройках.

Если при запуске появляется ошибка "Cannot find specified library", это означает, что не найдена библиотека материалов или сечений. Проверьте пути к библиотекам в настройках, возможно, они были изменены или удалены.

Если вы не можете сохранить проект, проверьте права доступа к папке проекта. Недостаточно прав или диск переполнен.

При возникновении проблем с активацией лицензии или сбоях при работе с облачными сервисами необходимо проверить соединение с интернетом.

Если результаты расчета кажутся нереалистичными, следует проверить корректность задания нагрузок и граничных условий, правильность выбора типа расчета, наличие материалов в библиотеке. После внесения корректировок следует выполнить расчет повторно.

Для анализа ошибок можно использовать вкладку "Логи", где сохраняется подробная информация о выполненных действиях и возникающих ошибках. При обращении в техническую поддержку обязательно прилагайте файл лога ошибок.

8.2. Часто задаваемые вопросы

Вопрос: Почему программа не определяет материалы из библиотеки при импорте?
Ответ: При импорте из форматов, не поддерживающих передачу свойств материалов, происходит автоматическое сопоставление по типу и плотности. Если материал не распознается, программа предлагает вручную выбрать его из библиотеки. Рекомендуется перед импортом проверить наличие соответствующего материала в библиотеке.

Вопрос: Как ускорить выполнение расчета на больших моделях?
Ответ: Для ускорения расчетов можно использовать следующие методы: уменьшить количество конечных элементов в зонах с небольшим градиентом напряжений, использовать более крупные конечные элементы, применить алгоритмы параллельных вычислений (при наличии многоядерного процессора), выполнять расчет с использованием видеокарты (CUDA/OpenCL), задать более жесткие критерии сходимости.

Примечание: При использовании упрощенных моделей точность может снизиться. Рекомендуется перед упрощением создать копию проекта и выполнить предварительный расчет для оценки приемлемости упрощений.

Вопрос: Как объединить несколько проектов в один?
Ответ: Через команду "Файл → Собрать проект" можно объединить несколько проектов в один. При этом автоматически перестраивается нумерация элементов и материалов. Рекомендуется перед объединением проверить, чтобы все объединяемые проекты были созданы в одной системе единиц и с одинаковыми стандартами оформления.

Важно! Если в объединяемых проектах использовались материалы с одинаковыми названиями, но разными характеристиками, система выведет предупреждение и предложит варианты разрешения конфликта.
